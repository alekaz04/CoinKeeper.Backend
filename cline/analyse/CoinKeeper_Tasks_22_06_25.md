## Технические детали интеграции Hangfire

### Конфигурация Hangfire

```csharp
// В Startup.cs
services.AddHangfire(configuration => configuration
    .SetDataCompatibilityLevel(CompatibilityLevel.Version_170)
    .UseSimpleAssemblyNameTypeSerializer()
    .UseRecommendedSerializerSettings()
    .UsePostgreSqlStorage(connectionString, new PostgreSqlStorageOptions
    {
        QueuePollInterval = TimeSpan.FromSeconds(10),
        JobExpirationCheckInterval = TimeSpan.FromHours(1),
        CountersAggregateInterval = TimeSpan.FromMinutes(5),
        PrepareSchemaIfNecessary = true,
        DashboardJobListLimit = 25000,
        TransactionSynchronisationTimeout = TimeSpan.FromMinutes(5),
        TablesPrefix = "hangfire"
    }));

services.AddHangfireServer(options =>
{
    options.WorkerCount = Environment.ProcessorCount * 2;
    options.Queues = new[] { "default", "payments", "notifications" };
});
```

### Структура задач

1. **Периодические задачи (RecurringJob)**:
   - Проверка плановых платежей каждые 15 минут
   - Очистка выполненных задач раз в день
   - Пересчет балансов раз в час

2. **Отложенные задачи (DelayedJob)**:
   - Выполнение конкретного планового платежа в назначенное время
   - Одноразовые отложенные платежи

3. **Фоновые задачи (BackgroundJob)**:
   - Немедленное выполнение операций
   - Отправка уведомлений

### Очереди задач

- **default**: Обычные задачи
- **payments**: Критически важные финансовые операции
- **notifications**: Уведомления пользователей

## Преимущества использования Hangfire

1. **Надежность**: 
   - Автоматические повторы при сбоях
   - Персистентность задач в базе данных
   - Обработка исключений

2. **Масштабируемость**: 
   - Возможность запуска на нескольких серверах
   - Балансировка нагрузки между воркерами
   - Очереди для приоритизации задач

3. **Мониторинг**: 
   - Встроенный dashboard для отслеживания задач
   - Статистика выполнения
   - История задач

4. **Гибкость**: 
   - Поддержка различных типов задач
   - Cron-выражения для сложных расписаний
   - Возможность отмены и перепланирования задач

5. **Интеграция**: 
   - Простая интеграция с ASP.NET Core
   - Поддержка Dependency Injection
   - Совместимость с Entity Framework
