# CoinKeeper

## Обзор

**CoinKeeper** — это backend-сервис для учёта личных финансов, предоставляющий REST API. Проект предназначен для самостоятельного изучения проектирования ПО, backend-разработки и деплоя с использованием C# (.NET, EF Core, Web API, Docker) без необходимости создания полноценного веб-интерфейса.

---

## Цели проекта

- Получить опыт проектирования и реализации API на .NET.
- Научиться работать с EF Core и проектировать реляционную базу данных.
- Освоить деплой и контейнеризацию с помощью Docker.
- Попрактиковаться в написании тестируемого и расширяемого кода.

---

## Архитектура

- **Backend:** .NET 8 Web API, EF Core, PostgreSQL.
- **Документация:** Swagger/OpenAPI.
- **Деплой:** Docker, docker-compose.
- **Логирование:** Serilog.
- **Мониторинг (опционально):** Prometheus, Grafana.

---

## Основные возможности (MVP)

- Регистрация и аутентификация пользователя.
- Добавление расходов и доходов (сумма, категория, дата, комментарий).
- Получение списка транзакций с фильтрацией и пагинацией.
- Просмотр баланса за выбранный период.
- Отчёты по категориям и периодам.
- Редактирование и удаление транзакций.
- Базовая аналитика: сумма расходов/доходов, топ категорий.
- Документация API (Swagger).
- Логирование и обработка ошибок.

---

## Возможности для развития (будущее)

- Поддержка нескольких валют.
- Повторяющиеся транзакции (например, ежемесячные платежи).
- Импорт/экспорт данных (CSV, Excel).
- Напоминания о регулярных платежах.
- Групповые финансы (совместный бюджет, роли пользователей).
- Интеграция с внешними API (например, курсы валют).
- Категории и подкатегории расходов/доходов.
- Визуализация данных (генерация графиков).
- История изменений транзакций (аудит).
- Роли и права доступа (админ, пользователь).
- Логирование действий пользователей.
- Мониторинг и алерты (Prometheus, Grafana).
- CI/CD для автоматического деплоя.

## План развития

1. **MVP**
   - Проектирование базы данных (EF Core, миграции).
   - Реализация REST API (CRUD для транзакций, отчёты).

2. **Базовая аналитика**
   - Фильтрация и сортировка транзакций.
   - Отчёты по категориям, периодам.
   - Баланс за период.

3. **Улучшение UX**
   - Валидация и обработка ошибок.

4. **Расширение функционала**
   - Повторяющиеся транзакции.
   - Импорт/экспорт.
   - Мультивалютность.
   - Напоминания.

5. **Интеграции и визуализация**
   - Интеграция с внешними сервисами (курсы валют, email-уведомления).

6. **DevOps и поддержка**
   - Логирование, мониторинг, алерты.
   - CI/CD (GitHub Actions, Docker Hub).

## Итог

CoinKeeper даст практический опыт во всех ключевых аспектах современной backend-разработки: проектирование API, работа с базой данных, интеграция с внешними сервисами, деплой и поддержка. Проект ориентирован на создание чистого и расширяемого API для учёта личных финансов.

## Пошаговый план развития проекта

### 1. Подготовка и инициализация проекта
- Создать репозиторий и структуру проекта на .NET.
- Настроить систему контроля версий (git, .gitignore).
- Подключить базовые инструменты: Docker, docker-compose, Swagger.

### 2. Проектирование базы данных
- Определить основные сущности: Пользователь, Транзакция, Категория.
- Описать связи между сущностями.
- Реализовать миграции с помощью EF Core.

### 3. Реализация базовой аутентификации и авторизации
- Добавить регистрацию и вход пользователя (например, JWT).
- Ограничить доступ к данным только для авторизованных пользователей.

### 4. CRUD для транзакций и категорий
- Реализовать эндпоинты для создания, получения, редактирования и удаления транзакций.
- Добавить работу с категориями (CRUD).

### 5. Фильтрация, сортировка, пагинация
- Добавить возможность фильтровать и сортировать транзакции по дате, категории, типу (расход/доход).
- Реализовать пагинацию для списков.

### 6. Отчёты и аналитика
- Реализовать получение баланса за период.
- Добавить отчёты по категориям и периодам.
- Реализовать базовую аналитику (суммы, топ категории).

### 7. Документация и тестирование
- Оформить документацию API через Swagger.
- Добавить unit- и интеграционные тесты для основных сценариев.
