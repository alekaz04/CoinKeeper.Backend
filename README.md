# CoinKeeper

## Описание проекта

CoinKeeper — это бэкенд-сервис для управления личными финансами, предоставляющий REST API. Проект разрабатывается в образовательных целях для изучения проектирования программного обеспечения, разработки бэкенда и развертывания с использованием современных технологий.

## Технологии

- **Бэкенд:** .NET 9, ASP.NET Core Web API, Entity Framework Core
- **База данных:** PostgreSQL
- **Документация:** Swagger/OpenAPI (NSwag)
- **Валидация:** FluentValidation
- **Маппинг объектов:** AutoMapper
- **Логирование:** Serilog
- **Контейнеризация:** Docker

## Архитектура

Проект следует многослойной архитектуре с четким разделением ответственности:

- **API слой:** Контроллеры, конечные точки API, запросы/ответы
- **Слой бизнес-логики:** Обработчики, сервисы, валидация, бизнес-правила
- **Слой доступа к данным:** Entity Framework, контекст данных
- **База данных:** PostgreSQL

## Текущие возможности

- Базовая структура проекта
- Начальная миграция базы данных
- Основные конечные точки API для создания и получения финансовых операций
- Централизованная обработка ошибок
- Документация API через Swagger

## Установка и запуск

### Требования
- .NET 9 SDK
- PostgreSQL
- Docker (опционально)

### Запуск проекта
1. Клонировать репозиторий
2. Настроить строку подключения к PostgreSQL в `src/CoinKeeper.Backend.Api/appsettings.json`
3. Выполнить миграции базы данных:
   ```
   dotnet ef database update --project src/Common/CoinKeeper.Infrastructure --startup-project src/CoinKeeper.Backend.Api
   ```
4. Запустить проект:
   ```
   dotnet run --project src/CoinKeeper.Backend.Api
   ```

### Запуск через Docker
```
docker-compose up -d
```
