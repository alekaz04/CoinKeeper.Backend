## Описание проекта

CoinKeeper — это бэкенд-сервис для управления личными финансами, предоставляющий REST API. Проект разрабатывается в образовательных целях для изучения проектирования программного обеспечения, разработки бэкенда и развертывания с использованием современных технологий.

Система позволяет пользователям отслеживать свои доходы и расходы, категоризировать финансовые операции, анализировать финансовое состояние и получать отчеты по различным периодам и категориям.

## Технологии

- **Фреймворк:** .NET 9 (последняя версия)
- **Веб-фреймворк:** ASP.NET Core Web API
- **ORM:** Entity Framework Core с Code-First подходом
- **База данных:** PostgreSQL
- **Аутентификация:** JWT (JSON Web Tokens)
- **Валидация:** FluentValidation
- **Маппинг объектов:** AutoMapper
- **Документация API:** Swagger/OpenAPI (NSwag)
- **Логирование:** Serilog (настроено, но не полностью реализовано)
- **Контейнеризация:** Docker

## Текущие возможности

### Аутентификация и пользователи
- Регистрация и аутентификация пользователей
- JWT-токены для авторизации
- Обновление токенов (Refresh Token)
- Привязка данных к конкретному пользователю

### Управление финансовыми операциями
- Создание операций (доходы и расходы)
- Получение операций по идентификатору
- Получение списка всех операций пользователя
- Обновление и удаление операций
- Типизация операций (доход/расход)

### Управление категориями
- Создание категорий для операций
- Получение категорий по идентификатору
- Получение списка всех категорий пользователя
- Обновление и удаление категорий

### Инфраструктура
- Централизованная обработка ошибок
- Валидация входных данных
- Документация API через Swagger
- Контейнеризация с использованием Docker

## Планы развития

- Реализация фильтрации и пагинации для списков операций и категорий

- Отчеты по категориям

### Будущие улучшения
- Поддержка нескольких валют
- Повторяющиеся транзакции

## Статус проекта

Проект находится на ранней стадии разработки. Реализованы базовые компоненты инфраструктуры и основные функции управления финансовыми операциями и категориями. Система аутентификации настроена, но требует дополнительной конфигурации для полноценной работы.

Текущий фокус разработки направлен на улучшение существующих функций, расширение API и реализацию отчетов и аналитики.
