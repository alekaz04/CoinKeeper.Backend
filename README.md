## Описание проекта

CoinKeeper — это современный бэкенд-сервис для управления личными финансами, предоставляющий REST API. Проект разрабатывается в образовательных целях для изучения проектирования программного обеспечения, разработки бэкенда и развертывания с использованием современных технологий .NET.

Система позволяет пользователям:
- Отслеживать доходы и расходы с привязкой к различным счетам
- Категоризировать финансовые операции для детального анализа
- Создавать и управлять плановыми операциями с автоматическим выполнением
- Анализировать финансовое состояние и получать отчеты
- Управлять несколькими счетами с автоматическим расчетом баланса

## Технологии

### Основной стек
- **Фреймворк:** .NET 9 (последняя версия)
- **Веб-фреймворк:** ASP.NET Core Web API
- **ORM:** Entity Framework Core с Code-First подходом
- **База данных:** PostgreSQL 16.3
- **Аутентификация:** JWT (JSON Web Tokens) с Refresh Token
- **Валидация:** FluentValidation
- **Маппинг объектов:** AutoMapper
- **Документация API:** Swagger/OpenAPI (NSwag)

### Инфраструктура и DevOps
- **Фоновые задачи:** Hangfire для планирования и выполнения задач
- **Логирование:** Serilog с поддержкой структурированного логирования
- **Контейнеризация:** Docker с multi-stage builds
- **CI/CD:** GitHub Actions с автоматической публикацией в GitHub Container Registry
- **Мониторинг:** Dozzle для просмотра логов, Portainer для управления контейнерами

## Архитектура и развертывание

### CI/CD Pipeline
Проект использует современный подход к непрерывной интеграции и развертыванию:

- **GitHub Actions**: Автоматическая сборка и тестирование для веток `dev` и релизных тегов
- **Контейнеризация**: Автоматическая сборка Docker-образов с multi-stage builds
- **Реестр образов**: Публикация в GitHub Container Registry (`ghcr.io`)
- **Проверка миграций**: Автоматическая валидация миграций EF Core в pipeline

### Развертывание
Приложение развертывается с использованием Docker Compose и включает:

- **Backend API**: Основной сервис приложения
- **PostgreSQL**: База данных с персистентным хранилищем
- **Миграции**: Автоматическое применение миграций при запуске
- **Мониторинг**: 
  - Dozzle для просмотра логов контейнеров
  - Portainer для управления Docker-контейнерами

### Безопасность конфигурации
- Чувствительные данные (строки подключения, JWT-ключи) хранятся в переменных окружения
- Использование User Secrets для локальной разработки
- Разделение конфигурации для разработки и продакшена

## Настройка и запуск

### Требования
- .NET 9 SDK
- PostgreSQL 16.3+
- Docker и Docker Compose (рекомендуется)

### Локальная разработка
1. Клонировать репозиторий
2. Настроить User Secrets для JWT и строки подключения к БД
3. Выполнить миграции: `dotnet ef database update`
4. Запустить проект: `dotnet run --project src/CoinKeeper.Backend.Api`

### Развертывание через Docker
1. Клонировать [репозиторий инфраструктуры](https://github.com/alekaz04/CoinKeeper.Infrastructure)
2. Настроить env-файлы с конфигурацией
3. Запустить: `docker-compose up -d`

- **Часовые пояса**: Корректная обработка временных зон для плановых операций
- **Транзакции**: Обеспечение атомарности операций в фоновых задачах

### Базовая функциональность (Приоритет 2)
- **Фильтрация и пагинация**: Реализация для всех списочных эндпоинтов

- **Поддержка валют**: Мультивалютность для счетов и операций (RUB, USD, EUR, GBP, CNY)

- **Экспорт данных**: Выгрузка операций и отчетов в CSV/Excel
